Objetivo del Proyecto

El objetivo principal es habilitar el envío de tickets de pedidos por WhatsApp desde el sistema ERP Odoo del vivero Chapasan, cumpliendo con todos los requisitos técnicos y legales que exige Meta (Facebook) para la aprobación de la WhatsApp Business API.

✅
Meta requiere que el negocio tenga una página web pública y verificable con Aviso de Privacidad y Términos y Condiciones. Este proyecto cubre ese requisito de forma gratuita usando GitHub Pages y el dominio existente.

Contexto y Decisiones Tomadas

🏗️

Infraestructura existente

Iván ya contaba con el dominio zenda-arquitectos.com registrado en Namecheap, alojado en Hostinger (plan Single – Website Builder) con nameservers ya apuntando a Hostinger. El dominio tiene un sitio de despacho de arquitectura activo.

💡

Decisión: Subdominio en lugar de dominio nuevo

Para evitar costos, se optó por crear el subdominio vivero.zenda-arquitectos.com para alojar la web del vivero. Meta acepta subdominios para la verificación del negocio.

⚠️

Limitación descubierta: Hostinger Website Builder

El plan Single de Hostinger (Website Builder) no incluye administrador de archivos ni FTP, y no permite agregar un segundo sitio sin costo adicional. Agregar un sitio PHP/HTML requería mejorar al plan Premium (~$80 MXN/mes).

🎯

Solución adoptada: GitHub Pages (gratuito)

Se utilizó GitHub Pages para alojar la página estática del vivero. Es completamente gratuito, soporta dominios personalizados con HTTPS automático, y Meta lo reconoce como hosting legítimo para verificación.

📧

Decisión: Alias de correo en lugar de buzón nuevo

El plan Free Business Email de Hostinger permite solo 1 buzón (ya usado por contacto@zenda-arquitectos.com). Se creó un alias de correo vivero@zenda-arquitectos.com que redirige al buzón existente. Solución gratuita y válida para Meta.

Roadmap Completo – Objetivo Final: WhatsApp API en Odoo

Una vez que la página web esté en vivo y verificada, los siguientes pasos para completar la integración de WhatsApp Business API con Odoo son:

  • ✅ FASE 1 — Presencia web verificable
    Subdominio DNS, alias de correo, página web con aviso de privacidad y T&C — Completado hoy 6 mayo 2026
  • FASE 2 — Crear cuenta en Meta Business Manager
    Ir a business.facebook.com → Crear cuenta nueva para Vivero Chapasan (separada del despacho de arquitectura si se prefiere). Agregar URL: https://vivero.zenda-arquitectos.com
  • FASE 3 — Verificación del negocio en Meta
    En Meta Business Manager: Configuración → Centro de Seguridad → Verificar negocio. Documentos necesarios: RFC, alta en SAT o comprobante de domicilio fiscal a nombre de Iván Fernández Montiel.
  • FASE 4 — Registrar número de WhatsApp Business API
    Usar un número telefónico exclusivo para el vivero (249 151 9638 u otro). Importante: ese número NO debe estar activo en WhatsApp normal. Se desvincula en WhatsApp antes de registrarlo en Meta. El número se verifica con SMS o llamada.
  • FASE 5 — Elegir proveedor de API (BSP)
    Recomendado para Odoo: 360dialog (~$5-10 USD/mes) o Meta Cloud API directo (gratuita, más técnica). El proveedor entrega: API Key, Phone Number ID, WhatsApp Business Account ID.
  • FASE 6 — Crear plantillas de mensajes en Meta
    Las plantillas para mensajes proactivos (tickets de pedidos) deben aprobarse en Meta Business Manager antes de usarse. Ejemplo de plantilla para ticket de pedido:

    "Hola {{nombre}}, tu pedido #{{num_pedido}} de {{cantidad}} charolas de {{especie}} ha sido confirmado. Fecha de entrega estimada: {{fecha}}. Vivero Chapasan."

    Meta revisa que las plantillas no sean promocionales en exceso. El proceso puede tomar de horas a 2 días.
  • FASE 7 — Configurar WhatsApp en Odoo
    En Odoo 16/17: Configuración → Técnico → WhatsApp → Cuentas de WhatsApp. Ingresar: Token de acceso (API Key del proveedor), Phone Number ID, WhatsApp Business Account ID, URL del webhook. Instalar módulo nativo whatsapp si no está instalado.
  • FASE 8 — Configurar plantillas en Odoo y probar
    Crear las plantillas dentro de Odoo vinculadas a los modelos de pedidos/ventas. Hacer prueba end-to-end: pedido en Odoo → ticket enviado por WhatsApp al cliente.
  • FASE 9 — Monitoreo de calidad del número
    Meta asigna una calificación de calidad al número (Alta/Media/Baja). Si los clientes bloquean el número, la calificación baja y Meta puede limitar o suspender el envío de mensajes. Monitorear en Meta Business Manager → Administrador de WhatsApp.
